# google-hashcode-zero-shot
Zero-shot solvers written by large language models for the 17 Google Hash Code qualification and final problems, 2014–2022. Three Claude models each write a C++ solver ten times per problem from the statement alone. Each solver is scored with [google-hashcode-judge](https://github.com/uran-lajci/google-hashcode-judge) and compared with the competition scoreboards.
